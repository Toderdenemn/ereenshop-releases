# ereenshop app releases

APK release assets for **ereenshop** (Эрээн–Монгол marketplace): `buyer-v<x>` (худалдан авагчийн апп), `seller-v<x>` (卖家端),
`sms-v<x>` (SMS gateway). Published by `tool/publish_apk.mjs` from the private source repository; ereenshop.mn/downloads/
is served from these assets (server `apk-sync` + `downloads/versions.json`). Source code lives in a separate private repository.
